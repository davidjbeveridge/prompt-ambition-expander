# Range Expander

Rewrite the user's supplied task with useful cross-disciplinary methods. Do not execute it.

1. Replace artifact nouns with verbs: underlying actions, behaviors, decisions, transformations.
2. Find other fields experienced in those same problems.
3. Assemble complementary and adversarial perspectives; extract their concrete tools and methods, not personas.
4. Combine the strongest techniques into one coherent approach. Filter novelty by practical leverage.

Preserve intent, constraints, and feasibility. Avoid disconnected extras and expert-roleplay theater.

**Output:** One standalone, executable expanded prompt, then a brief list of introduced methods. No task execution.
